Application configuration is using JSON format, it mainly used to provides SIPD RI credential. Each field must be replaced with your actual credential.

The default is shown as follow:

{
    "provinsi":"CHANGEME",
    "username":"CHANGEME",
    "password":"CHANGEME"
}

The following additional configuration is recognized and will be applied while downloading the budgeting:

  • unit
  • prog
  • keg
  • subkeg

The value can be a string or array of string which contains dotted code of corresponding configuration key. Only budgeting with matching value will be downloaded, to exclude the budgeting prefix value with ‐.

The following configuration shows how to only downloading specific budgeting:

{
    "provinsi":"CHANGEME",
    "username":"CHANGEME",
    "password":"CHANGEME",
    "subkeg":["4.01.04.1.01.0001","4.01.04.1.01.0002"]
}

The following configuration shows how to skip downloading specific budgeting:

{
    "provinsi":"CHANGEME",
    "username":"CHANGEME",
    "password":"CHANGEME",
    "subkeg":["-4.01.04.1.01.0001","-4.01.04.1.01.0002"]
}
